# helenomatos.github.io

Coursework site for the Front-end module of my BSc in Computing at Dorset College Dublin. It's hosted on GitHub Pages and collects the HTML and CSS exercises from class.

**Live:** https://helenomatos.github.io

My main portfolio is at **[portfolio.helenomatos.com](https://portfolio.helenomatos.com)**.

## Contents

| Folder               | What's inside                                                                             |
| -------------------- | ----------------------------------------------------------------------------------------- |
| `exercises/`         | Class exercises: themed pages, five sample layouts and hero blocks (text, image and video) |
| `apps/hero/`         | Hero-block generator apps (`prompts/`) and the pages they export (`outputs/`)               |
| `portfolio/smoothies/` | A one-page smoothie bar layout                                                          |
| `index.html`         | The index page that links to everything above                                             |

## Run

No build step. Open `index.html` in a browser, or visit the live site.
